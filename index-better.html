3

First AI Agent

LangChain4j AiService + 2 @Tool methods (DB query + health). LLM picks which tool to call autonomously.

4

RAG Pipeline

Ingest 10 Java files into pgvector. Chunk by method. Semantic search: "Which class handles payments?"

5

Reactive Streaming

WebFlux SSE endpoint + HTML EventSource. Tokens appear one-by-one. Java 21 Virtual Threads for LLM call.

6

PII + Injection Defense

Spring filter on /api/ai/*. Mask PAN/Aadhaar. Detect "ignore instructions" → reject 403.

7

Semantic Caching

Embed question → Redis similarity >0.92 → return cached ($0). Miss → call LLM. 2nd query: <50ms.

8

Kafka Ingestion

Producer → Kafka topic → Consumer strips PII, chunks, embeds, stores pgvector. DLQ for failures.

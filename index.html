🎤 Interview Playbook

Exact answers that make you sound like a veteran.

"Your AI experience?"
Production LangChain4j agents with autonomous @Tool calling against live K8s clusters and pgvector RAG. Streamed results in real-time via WebFlux SSE.
"How handle AI costs?"
Semantic Redis cache (0.92 threshold) + token compaction + model routing. Cut Bedrock billing by 52%.
"Data security?"
Zero-trust Java filter interceptor masks PII via regex. Rejects prompt injection. No sensitive data leaves VPC.
"Scale?"
Java 21 Virtual Threads (50K concurrent). Kafka buffering. WebFlux non-blocking streaming to thousands of clients.
"Why Java not Python?"
LangChain4j = native JVM. No new runtime, no new deploy pipeline, no new security audit. Direct Spring Boot integration.
"System design?"
Reactive ingestion → PII filter → semantic cache → LangChain4j agent → @Tool execution → SSE streaming. Emphasize cost + security.
